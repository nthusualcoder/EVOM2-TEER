## 1. 장비 구성 확인

| 보유 장비 | 정체 | 역할 |
|---|---|---|
| EVOM2 voltohmmeter | WPI Epithelial Volt/Ohm Meter | TEER(저항) 및 막전위(mV) 측정 본체 |
| 팁 2개 (녹색 젓가락 모양) | STX2 "chopstick" 전극 (한 세트, RJ-11 플러그) | 배양 well에 꽂아 측정 |
| 동축 오디오선 | BNC 케이블 (또는 BNC ↔ 3.5 mm 등) | EVOM2 **OUTPUT (BNC)** → NI DAQ 아날로그 입력 |
| National Instruments 장비 | **NI USB-6003** DAQ (16비트, 100 kS/s, 나사 단자형) | 아날로그 전압을 USB로 PC에 전달 |

EVOM2 자체에는 USB/RS-232 포트가 **없습니다**. 전면의 **OUTPUT BNC 단자**에서 나오는 아날로그 전압을
NI DAQ로 읽어서 PC에 저장하는 것이 유일한 디지털 기록 방법입니다.

### EVOM2 전면 패널
- **INPUT (RJ-11, 전화선 모양)** : STX2 전극 또는 1000 Ω 테스트 저항 연결
- **OUTPUT (BNC)** : 아날로그 출력 → NI DAQ
- **FUNCTION** 스위치 : OHMS(저항) / MILLIVOLTS(전압)
- **R ADJ** : 1000 Ω 테스트 저항으로 보정하는 나사
- **POWER** : I(켜짐) / O(꺼짐)
- 뒷면/측면 : 충전기 잭 (12 V DC)

### 아날로그 출력 스케일 (매뉴얼 Specifications, p.18)

| 모드 | 스케일 | 예시 |
|---|---|---|
| OHMS | **1 Ω = 1 mV** | 1000 Ω → 1.000 V, 9999 Ω → 약 10 V |
| MILLIVOLTS | **1 mV = 10 mV** (10배 증폭) | 표시 +50.0 mV → 출력 +0.500 V |

→ NI DAQ 아날로그 입력 범위는 **±10 V**로 설정하면 됩니다.

**실측 (2026-09-07 기록 기준, 2026-10-04 정정)**: 맨 처음 RSE 테스트 15행에서는 출력이 0 V ↔ V 를 오가는 사각파로 읽혀 단순 평균이 화면값의 절반(화면 1322 Ω ↔ 평균 661 Ω)이었습니다. 그러나 그 뒤의 기록 331행 중 325행(DIFF 51행은 전부)은 **DC 로 읽혔고 화면값과 일치**했습니다 (예: 1320 Ω ↔ 1.320 V, 샘플 sd 5 mV). 따라서 "출력은 항상 사각파"라고 썼던 이전 설명은 틀렸습니다. 정상 배선에서는 DC 이고, 사각파는 첫 테스트 때의 배선 상태에서만 나온 것으로 보입니다 (원인은 확인하지 못함). 프로그램의 신호 처리 "자동"은 두 경우 모두 화면값과 맞게 계산합니다 (사각파면 진폭 = 위쪽 40% 샘플 평균 − 아래쪽 40% 샘플 평균, DC 면 평균).

## 2. 배선 (연결 방법)

```
[STX2 전극] --RJ-11--> [EVOM2 INPUT]
[EVOM2 OUTPUT (BNC)] --동축 케이블--> [NI DAQ 아날로그 입력 AI0]
[NI DAQ] --USB--> [PC]
```

### NI 장비 = NI USB-6003 (2026-09-07 확인)
USB-6001/6002/6003 세 모델은 핀 배치가 같습니다. 매뉴얼: `NI_USB-6001_6002_6003_User_Guide_EN.pdf` (p.9 Pinout).
아날로그 입력 범위 ±10 V 고정, 나사 단자 2블록(AI/AO 쪽, DIO 쪽). 선은 6 mm 벗겨서 일자 드라이버로 조입니다.

**AI 쪽 16핀 단자 (라벨 `AI ⏚ 0 +0− 4 …` 가 있는 블록)** — 사진에서 `AI` 글자가 있는 끝이 1번 핀:

| 핀 | 라벨 | 신호 | EVOM2 연결 |
|---|---|---|---|
| 1 | ⏚ | AI GND | **검은 선 (BNC 바깥 실드)** |
| 2 | 0 (+0) | AI 0 / AI 0+ | **노란 선 (BNC 중심 도체)** |
| 3 | 4 (0−) | AI 4 / AI 0− | **DIFF 방식(프로그램 기본)일 때 검은 선을 여기에도 연결** (짧은 점퍼선으로 1번과 3번을 이어도 됨). RSE면 비움 |
| 4 | ⏚ | AI GND | |
| 5~12 | 1,5 / 2,6 / 3,7 | AI 1~7 | 비움 |
| 13 | ⏚ | AI GND | |
| 14~15 | AO 0, AO 1 | 아날로그 출력 | **절대 연결 금지** (출력 단자) |
| 16 | ⏚ | AO GND | |

- DIO 쪽 블록(P0.x, P1.x, PFI, 5V)은 이번 작업에 전혀 쓰지 않습니다. 특히 **5V 단자에 신호선을 꽂지 마세요.**
- **입력 방식 (RSE / DIFF)** — DAQ가 전압을 "무엇을 기준으로" 재는지의 차이입니다.
  - **RSE** (Referenced Single-Ended): AI0 전압을 DAQ 자체 접지(AI GND) 기준으로 잽니다. 선 2개(신호, GND)만 필요. EVOM2처럼 배터리로 도는 floating 장비 + 짧은 케이블에는 이것으로 충분하며 NI 매뉴얼 Table 6도 허용합니다.
  - **DIFF** (Differential): AI0+와 AI0−(=AI4) 두 단자의 차이를 잽니다. 두 선에 같이 실리는 잡음(형광등, 컴퓨터 노이즈)이 상쇄되어 잡음에 강합니다. **프로그램 기본값 (2026-09-07 변경).** floating 장비에서는 AI− 를 GND에도 묶어줘야 값이 떠다니지 않으므로 아래 배선을 지켜야 합니다.
  - **DIFF 배선 (기본)**: 노란 선 → 2번(AI0+), 검은 선 → 3번(AI4 = AI0−) **그리고** 1번(AI GND)에도 같이 연결 (검은 선을 두 가닥으로 나누거나, 1번–3번 사이를 짧은 점퍼선으로 이어도 됨). 3번을 비워 두면 값이 서서히 떠다니니 주의. 입력 방식을 바꾸면 프로그램 상태줄에 해당 배선이 표시됩니다.
- **신호 처리 (자동 / 사각파 진폭 / 단순 평균)** — 1초 동안 받은 1000개 샘플을 숫자 하나로 만드는 방법입니다.
  - **단순 평균**: 1000개의 평균. 출력이 DC일 때(정상 배선에서의 보통 상태) 맞는 방법입니다. 신호가 0↔V 사각파로 읽힐 때만 화면값의 절반이 나옵니다 (1절의 실측 참고).
  - **사각파 진폭**: 샘플을 크기순으로 정렬해 위쪽 40% 평균 − 아래쪽 40% 평균. 사각파의 "높은 구간 − 낮은 구간" 즉 진폭 V를 구하며, 이것이 EVOM2 화면값과 일치합니다.
  - **자동** (기본): 샘플 표준편차가 평균의 30%를 넘으면 사각파로 보고 진폭을, 아니면 평균을 씁니다. 그냥 자동으로 두면 됩니다. 어떤 방법이 쓰였는지 숫자 아래 줄과 CSV의 method 열에 남습니다.
- 동축선 색이 의심되면 멀티미터로 BNC 중심핀 ↔ 노란 선 통전 확인, 또는 1000 Ω 테스트 저항 상태에서 DAQ 값이 **+1.0 V**(정상) / **−1.0 V**(선 바뀜)인지 확인.
- NI 매뉴얼 권장: 단자에 물리는 선 길이 0.5 m 이내, 실드는 가까운 GND 단자에.

### 측정 전 필수 사항 (매뉴얼 강조)
1. **EVOM2 충전기를 반드시 분리**하고 배터리로 동작시킵니다. 충전기가 연결되면 절연이 깨져 값이 흔들립니다.
2. 전원 켜고 **20분 워밍업**.
3. 1000 Ω 테스트 저항을 INPUT에 꽂고 FUNCTION=OHMS 에서 화면이 **1000** 이 되도록 **R ADJ** 나사로 보정.
4. 같은 상태에서 DAQ로 읽은 전압이 **약 1.000 V** 인지 확인 → DAQ 스케일(1 mV/Ω) 검증 완료.
5. 값이 흔들리면 노트북을 배터리로 쓰거나, DAQ 접지(ground loop) 연결을 점검합니다. 매뉴얼 Troubleshooting 에도 "기록 장치 연결이 노이즈 원인이 될 수 있다"고 되어 있습니다.

## 3. 데이터 얻는 방법 (3가지)

### 방법 A. NI MAX 테스트 패널 (※ 이 PC에는 NI MAX가 설치되어 있지 않음, 2026-09-07 확인)
0. 이 PC에는 NI-DAQmx 런타임만 있고 NI MAX 프로그램(NIMax.exe)이 없습니다. 쓰려면 ni.com에서 **NI-DAQmx 전체 설치본**(NI Package Manager, 무료)을 받아 설치할 때 "NI Measurement & Automation Explorer" 항목을 포함해야 합니다. NI MAX 없이도 방법 B 스크립트는 정상 동작합니다 (`--list`로 장비 인식 확인, `--continuous 0.5`가 테스트 패널 대용).
1. NI DAQ를 USB로 연결 → 시작 메뉴 검색창에 **NI MAX** 입력 → 실행.
2. 왼쪽 트리 `내 시스템 > 디바이스와 인터페이스 > NI USB-6003 "Dev1"` 선택.
3. **테스트 패널** → Analog Input 탭 → 채널 `Dev1/ai0`, 모드 RSE, 범위 ±10 V → **시작**.
4. 그래프의 전압 × 1000 = Ω (OHMS 모드). 빠른 확인용이며 자동 저장은 안 됩니다.

### 방법 B. 측정 프로그램 `EVOM2_TEER` (권장, 창 하나로 끝)

실행 (셋 중 하나):
- **`EVOM2_TEER 배포용 (이 폴더만 다른 PC로 복사)\2_EVOM2_TEER.exe` 더블클릭** — Python 없이 아무 Windows PC에서 실행. 다른 PC로 가져갈 때는 배포용 폴더를 통째로 복사하고, 안의 `0_읽어보세요_설치순서.txt` 순서대로 (1) NI-DAQmx 드라이버 설치 → (2) USB-6003 연결 → (3) exe 실행. 같은 exe가 `EVOM2 장비 코드\EVOM2_TEER.exe` 에도 있고, GitHub 릴리스(https://github.com/nthusualcoder/EVOM2-TEER/releases/latest)에서 받아도 됩니다.
- 맨 위 폴더의 `EVOM2_TEER_실행.bat` 더블클릭 (이 PC의 Python 3.10 으로 `EVOM2 장비 코드\EVOM2_TEER.py` 실행)
- PowerShell 에서 `EVOM2 장비 코드` 폴더로 이동한 뒤 `python EVOM2_TEER.py` (python 이 PATH 에 없으면 `%LOCALAPPDATA%\Programs\Python\Python310\python.exe`)

.py 로 실행하려면 NI-DAQmx 드라이버와 `pip install nidaqmx` 가 필요합니다 (exe 는 드라이버만 있으면 됨).

사용 순서:
1. USB-6003을 USB로 꽂고 **[새로고침]** → 목록에서 `Dev1/ai0 [USB-6003]` 선택. (장비가 없으면 "시뮬레이션" 항목으로 연습 가능)
2. EVOM2의 FUNCTION 스위치와 같은 **모드**(OHMS / MILLIVOLTS) 선택.
3. **[연결]** → 큰 숫자로 실시간 값(최근 1초)과 30초 그래프가 표시됩니다. 1000 Ω 테스트 저항을 꽂으면 약 1000 Ω이 보여야 합니다.
   - "신호 처리"는 **자동**으로 두면 됩니다 (사각파면 진폭, DC면 평균). 숫자 아래 줄에 어떤 방법을 썼는지와 샘플 sd가 표시됩니다. sd가 수 mV면 DC, 수백 mV면 사각파로 읽힌 것입니다.
   - 그래도 화면값과 다르면: EVOM2 화면 숫자를 "보정" 칸에 입력하고 **[보정]** → 비율이 `evom2_settings.json`에 저장되어 다음 실행에도 적용됩니다. **[해제]** 로 되돌립니다.
   - 값이 사방으로 튀지 않고 **일정하게 계속 감소/증가**하면 EVOM2 화면과 비교하세요. 화면값도 같이 변하면 전극 쪽(용액 밖에 있거나 마르는 중, 공기 중 값은 무효), 화면은 그대로인데 프로그램 값만 변하면 배선 쪽(DIFF 인데 3번 단자가 비었거나 케이블 접촉 불량)입니다.
4. **blank (3번 칸)**: 세포 없는 insert(배지만)에 전극을 넣고 안정되면 **[blank 측정 시작]** → 정한 시간(기본 **30초**) 동안의 평균이 blank로 저장됩니다. 진행 중에는 경과 초와 지금까지의 평균이 표시되고, 끝나면 평균과 변동폭(±)이 표시되며 CSV에 `blank` 행으로도 남습니다. 측정 중에는 전극을 움직이지 마세요. 이전에 잰 값을 알고 있으면 칸에 직접 입력 후 [입력값 적용]. 이후 모든 기록에 R−blank와 TEER가 같이 계산됩니다.
   - **그래프**: 실선(왼쪽 축) = EVOM 값(Ω), 점선(오른쪽 축) = TEER(Ω·cm²). 큰 숫자 옆에도 TEER가 같이 표시됩니다.
   - 오른쪽 위 **[Claude Code UI]** 버튼: 어두운 배경 + 주황 포인트 테마로 바뀝니다. 다시 누르면 기본 테마. 선택은 기억됩니다.
5. **Well 선택 (실시간 값 오른쪽의 플레이트 그림)**: 실제 플레이트처럼 **왼쪽 위(A1 쪽) 모서리가 모따기된** 윤곽 안에 well 이 그려져 있어, 플레이트 방향을 맞춰 보기 쉽습니다. 측정할 well 을 **클릭**하면 그 well 이 선택되고 4번 칸의 라벨이 `B3` 처럼 바뀝니다. Insert 종류(24 / 12 / 6 / 96-well)를 바꾸면 그림도 바뀝니다.
   - 진한 색 = 오늘 측정한 well, 연한 색 = 이전 기록만 있는 well, 빈 원 = 기록 없음, 굵은 테두리 = 지금 선택한 well. 원 안의 숫자는 가장 최근 기록의 **마지막 3초 평균 TEER** 입니다.
   - **순차 기록**: "기록이 끝나면 다음 well 로"가 켜져 있으면 기록이 끝날 때마다 A1→A2→…→A6→B1 순서로 다음 well 이 자동 선택됩니다. 전극을 다음 well 로 옮기고 [기록](또는 그림을 클릭한 뒤 Enter)만 누르면 됩니다. 건너뛸 때는 원하는 well 을 클릭. 더블클릭하면 선택과 동시에 기록이 시작됩니다.
   - 라벨 칸에 well 이름이 아닌 글자(예: `control`)를 직접 써도 기록되지만 그림과 시간 추적 그래프에는 나오지 않습니다.
6. **기록 (4번 칸)**: Insert 종류(드롭다운, 기본 24-well)와 막 면적(cm²) 확인 → 라벨 확인 → 기록 방식 선택 → **[기록]**. 기록하는 동안 들어오는 값은 **초당 5행씩 모두** CSV 에 저장됩니다.
   - **수동**: [기록]을 누른 뒤 [정지]를 누를 때까지.
   - **반자동**: 정한 시간(기본 10초) 동안 저장하고 자동 종료.
   - **자동 (well 순서대로 이동)**: **N초 측정 → M초 휴식 → 바로 옆 well N초 측정 → …** 을 **K개 well** 만큼 반복합니다 (기본 10초 / 5초 / 6개). 휴식 동안에는 저장하지 않고, 다음 well 이 플레이트 그림에 미리 선택되며 "전극을 A3 로 옮기세요"와 남은 초가 표시됩니다. 측정 시작과 끝에 알림음이 납니다. A6 다음은 B1 이고 플레이트 마지막 well(24-well 은 D6)에서 끝납니다. 중간에 [정지]하면 그때까지 잰 well 은 남고 나머지는 취소. 휴식 0초면 쉬지 않고 바로 다음 well.
   - **대표값 = 마지막 3초 평균**: 기록이 끝날 때마다 그 기록의 마지막 3초(0.2초 간격 15행) 평균을 계산해 6번 표에 굵은 강조 행("마지막 3초 평균")으로 넣고 상태줄에 표시합니다. 전극을 옮긴 직후 흔들리는 앞부분이 빠집니다. 3초보다 짧은 기록은 전부 평균합니다. 플레이트 숫자와 시간 추적 그래프도 이 값을 씁니다. CSV 에는 원래 행이 모두 남으므로 다른 구간으로 다시 계산할 수도 있습니다.
   - 각 행에는 `run_id`(기록 시작 시각, well 마다 새로 붙음)와 `elapsed_s`(경과 초)가 붙습니다.
   - **중단**: 저장 실패(엑셀이 CSV 를 열고 있음 등)나 DAQ 오류로 기록이 끊기면 "중단됨"으로 표시되고 다 잰 것으로 치지 않으며 다음 well 로 넘어가지 않습니다. CSV 에는 그 기록 뒤에 `rec_mode` 가 `중단` 인 표시 행이 하나 붙어(파일이 잠겨 있었으면 다음에 쓸 수 있을 때) 플레이트 숫자와 시간 추적 그래프에서 빠집니다. 이미 저장된 행은 지우지 않습니다. 원인을 해결하고 같은 well 을 다시 재면 됩니다. 자동 기록의 **휴식 중**에 DAQ 오류가 나면 이미 끝난 well 은 그대로 두고 "(다음 well) 부터 다시 시작하세요"라고 알립니다.
   - 프로그램 오류는 창으로 알리고 프로그램 폴더의 `evom2_error.log` 에 남깁니다. 측정은 계속됩니다.

## 4. TEER 계산 (매뉴얼 Appendix A)

1. 세포 없는 insert(배지만) 저항 = **R_blank** (보통 80~200 Ω)
2. 세포 있는 insert 저항 = **R_total**
3. 진짜 조직 저항 **R_tissue = R_total − R_blank**
4. 보고값(단위면적 저항) **TEER (Ω·cm²) = R_tissue × 막 유효면적 (cm²)**
   - 기기 화면의 숫자는 **그냥 Ω** 입니다 (Ω/cm²도 Ω·cm²도 아님).
   - **왜 나누기가 아니라 곱하기인가**: 저항은 병렬 회로처럼 동작합니다. 같은 세포층이라도 막이 2배 넓으면 전류가 지나갈 길이 2배라 저항은 **절반**으로 읽힙니다 (R ∝ 1/면적). 그래서 "면적과 무관한 세포층 고유값"을 얻으려면 작아진 만큼 되돌려 주어야 하고, 그것이 **× 면적**입니다. 나누면 넓은 막일수록 값이 더 작아져 반대로 틀어집니다. 이 때문에 단위도 Ω·cm² 이고, 매뉴얼 Appendix A와 TEER 리뷰 논문(Srinivasan et al., *J Lab Autom* 2015, 20(2):107)도 "TEER = R_tissue × M_area" 로 씁니다. 논문에 가끔 보이는 "Ω/cm²"는 표기 오류입니다.
   - 예: 1 cm² 막이 500 Ω이면 5 cm² 막은 100 Ω. 둘 다 × 면적 = 500 Ω·cm² 로 같은 세포층. (나누면 500 vs 20 으로 달라짐)
   - 값의 크기가 다르게 나오는 다른 이유: 전극 간 거리, blank 차감 여부, 24 mm insert에서의 전류 불균일. 이는 면적과 별개입니다.
   - 프로그램이 자동 계산합니다. 사용하는 insert 막 면적(제조사 사양서 값):

   | insert | Corning Transwell (기본값) | Falcon | Greiner ThinCert | Millicell |
   |---|---|---|---|---|
   | 24-well (6.5 mm) | **0.33 cm²** | 0.3 | 0.336 | 0.33 |
   | 12-well (12 mm) | **1.12 cm²** | 0.9 | 1.131 | 1.12 |
   | 6-well (24 mm) | 4.67 cm² | 4.2 | 4.524 | 4.2 |

5. 24 mm(6-well) insert는 STX2 전극으로 잰 값을 면적 환산하지 말 것 (전류가 막 전체에 고르게 못 퍼져 1.8~2.2배 크게 나옴, Endohm 챔버 필요). 24-well, 12-well은 문제 없음.

## 5. 전극(STX2) 취급 요령
- 긴 쪽 전극이 well 바닥에 닿고 짧은 쪽이 insert 안에 들어가게, **수직으로, 매번 같은 깊이/각도**로.
- 측정 중 손을 움직이지 말 것 (값이 흔들림).
- 샘플 간에는 증류수가 아닌 **배지로 헹구기**. 사용 후 증류수 헹굼 → 건조 보관.
- 소독: 70% 에탄올 30분 이내 / 5% 차아염소산나트륨 가능. **오토클레이브·UV·암모니아 금지.**
- 저항만 잴 때는 평형화 불필요. 전압(mV) 잴 때는 전원 OFF + OHMS 위치로 전극을 KCl/배지에 담가 수 시간 평형화.

## 8. GitHub 저장소와 새 버전 배포

- 저장소: https://github.com/nthusualcoder/EVOM2-TEER (공개. 공개여야 각 PC 의 프로그램이 로그인 없이 업데이트를 받을 수 있음)
- 릴리스(실행 파일): https://github.com/nthusualcoder/EVOM2-TEER/releases/latest
- **새 버전 내기** (개발 PC, 이 폴더가 git 저장소인 상태):
  1. `EVOM2 장비 코드\EVOM2_TEER.py` 를 고치고 맨 위의 `APP_VERSION` 을 올립니다 (예: `"1.0.0"` → `"1.0.1"`).
  2. `EVOM2 장비 코드` 폴더에서 `python release.py publish "바뀐 내용 한 줄"` 실행.
     → exe 빌드, git commit · 태그(v1.0.1) · push, GitHub 릴리스 생성, exe 업로드까지 한 번에 합니다.
  3. 각 PC 의 프로그램은 다음 실행 때 버튼이 `업데이트 v1.0.1` 로 바뀌고, 누르면 받아서 바꿉니다.
- GitHub 로그인은 이 PC 의 Git Credential Manager 에 저장된 것을 씁니다 (git push 가 되는 상태면 됨). 다른 PC 에서 배포하려면 그 PC 에서 이 저장소를 clone 한 뒤 git push 를 한 번 해서 로그인하면 됩니다.
- exe 만 다시 만들 때는 `build_exe.bat` 더블클릭 (GitHub 에는 올리지 않음).
