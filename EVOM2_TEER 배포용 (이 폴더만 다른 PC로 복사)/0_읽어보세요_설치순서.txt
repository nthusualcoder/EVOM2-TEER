EVOM2 TEER 측정 프로그램 - 다른 PC 설치 순서   (2026-10-11, 프로그램 v1.0.1)
============================================================

이 폴더 하나를 USB 메모리 등으로 통째로 복사한 뒤, 번호 순서대로 실행하세요.
(인터넷이 되는 PC 라면 2_EVOM2_TEER.exe 는 https://github.com/nthusualcoder/EVOM2-TEER/releases/latest 에서
 받아도 됩니다. NI 드라이버는 [1] 의 설치기나 NI 사이트에서 받습니다.)

[1] 1_NI-DAQmx_드라이버_설치_25.8.exe   (처음 한 번만, 관리자 권한, 인터넷 필요)
    - NI(National Instruments) 정식 설치 프로그램입니다 (NI-DAQmx 2025 Q4 = 25.8, NI 디지털 서명 확인됨).
    - 더블클릭 → NI Package Manager 창이 뜸 → 약관 동의 → "NI-DAQmx" 선택된 상태로 [다음]/[설치]
      * 설치 항목을 고를 수 있으면 "NI-DAQmx Runtime" 만으로 충분합니다. 전부 설치해도 됩니다.
      * NI 계정 로그인 창이 뜨면 건너뛰어도 됩니다 (드라이버는 무료).
    - 설치가 끝나면 재부팅.
    - ※ 이 설치 프로그램은 9.6 MB짜리 "온라인 설치기"라서, 실행하면 NI 서버에서 실제 드라이버(약 1~2 GB)를
      내려받습니다. 따라서 설치하는 순간에는 인터넷이 필요합니다. 완전 오프라인용 설치본은 NI 사이트에서
      로그인해야만 받을 수 있어 여기에 넣지 못했습니다. (설치 후에는 인터넷 없이 동작합니다.)
    - 이미 NI-DAQmx가 설치된 PC(예: LabVIEW 쓰는 PC)라면 이 단계는 건너뜁니다.

[2] USB-6003 을 USB 케이블로 PC에 연결
    - 처음 꽂으면 Windows가 장치를 인식하는 데 10~30초 걸립니다. 장치의 파란 LED가 켜지면 준비 완료.
    - EVOM2 OUTPUT(BNC) ↔ USB-6003 배선은 가이드 2절 참고 (DIFF: 노란선→2번, 검은선→1번과 3번).

[3] 2_EVOM2_TEER.exe   (측정 프로그램, Python 설치 불필요)
    - 처음 실행 시 Windows SmartScreen "알 수 없는 게시자" 경고가 뜨면 [추가 정보] → [실행].
    - V3 같은 백신이 "프로그램 실행 알림" 창을 띄우면 [허용]. (서명 없는 자체 제작 프로그램이라 뜨는 확인 창, 새 버전마다 뜰 수 있음)
    - 첫 실행은 압축 해제 때문에 5~10초 걸립니다.
    - 프로그램 위쪽 [새로고침] → 장비 목록에 "Dev1/ai0 [USB-6003]" 이 보이면 성공.
      "시뮬레이션"만 보이고 상태줄에 "NI-DAQmx 드라이버를 찾지 못했습니다"가 뜨면 [1]번 드라이버가 설치되지 않은 것입니다.
    - 측정 데이터(CSV)와 설정 파일은 이 폴더 안에 만들어집니다 → 폴더에 쓰기 권한이 있어야 합니다.
      C:\Program Files 안에는 두지 마세요. 바탕화면이나 문서 폴더가 좋습니다.

[4] 사용법
    - EVOM2_연결_및_데이터수집_가이드.md  (메모장이나 VS Code로 열림) 의 3절 "방법 B" 참고.
    - 요약: 연결 → 모드(OHMS) 확인 → 세포 없는 insert에서 [blank 측정 시작](30초) → insert 종류 선택 →
      오른쪽 플레이트 그림(왼쪽 위 모따기 = A1 쪽)에서 well 클릭 → 기록 방식 선택 → [기록] / [정지].
      · 자동: N초 측정 → M초 휴식(전극을 옆 well 로) → 다음 well … K개 well 을 알아서 진행합니다.
      · 한 번의 기록을 대표하는 값 = 마지막 3초 평균 (표의 굵은 행, 플레이트 숫자, 그래프).
      TEER(Ω·cm²) = (R − blank) × 면적 이 자동 계산됩니다.
    - [시간 추적 그래프] 버튼: 폴더 안 CSV 들을 파일 수정 날짜 순서로 놓고 well 별 패널로 일간 추이를 봅니다.
      하루에 CSV 하나(기본 파일명이 날마다 바뀜), 한 실험의 CSV 는 한 폴더에 모아 두세요.

[5] 업데이트
    - 프로그램 오른쪽 위 [업데이트 확인]. 새 버전이 있으면 버튼이 "업데이트 v…" 로 바뀌고,
      누르면 GitHub 에서 받아 바꾼 뒤 다시 실행합니다 (설정·데이터는 그대로, 인터넷 필요).
      백신이 "프로그램 실행 알림"을 띄우면 [허용]을 누르세요. 막히면 지금 버전으로 그대로 계속됩니다.
    - v1.0.0 이전 exe 에는 이 버튼이 없으니, 그런 PC 는 이 폴더의 2_EVOM2_TEER.exe 로 한 번 바꿔 주세요.

요구 사양: Windows 10/11 64비트, USB 포트 1개, NI USB-6001/6002/6003.
문제가 생기면: 상태줄 메시지를 그대로 적어서 문의.
